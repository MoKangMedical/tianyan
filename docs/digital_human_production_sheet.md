# 天眼数字人出片单

## 统一设置
- 语言：中文
- 语气：专业、克制、清楚
- 节奏：中速偏稳
- 适用配音：`default_zh`
- 视频比例：9:16 为主，必要时补 16:9

## 1. 课程导学视频
- 目标：进入课程前先建立判断框架
- 时长：60-90 秒
- 画面：数字人正面 + 标题卡 + 关键词浮层
- 必备元素：标题、三条关键词、结尾 CTA

## 2. 产品介绍视频
- 目标：官网或宣传页快速说明平台价值
- 时长：60-90 秒
- 画面：数字人 + 平台页面录屏 + 图表卡片
- 必备元素：平台定位、核心能力、适用场景

## 3. 案例复盘视频
- 目标：把复杂案例讲清楚
- 时长：90-120 秒
- 画面：数字人 + 案例页截图 + 渠道排序图
- 必备元素：问题、方法、结果、结论

## 4. 客户汇报视频
- 目标：会前或会后快速统一结论
- 时长：60 秒
- 画面：数字人 + 3 条要点卡
- 必备元素：一个结论、两条证据、一步建议

## 5. 直播预热视频
- 目标：给直播间预热
- 时长：45-60 秒
- 画面：数字人 + 时间提醒 + 提纲卡
- 必备元素：直播主题、三个要讲的点、引导预约

## 6. 销售跟进视频
- 目标：会后跟进和二次转化
- 时长：60 秒
- 画面：数字人 + 客户问题摘要卡
- 必备元素：三件事总结、下一步建议、行动入口

## 出片检查清单
- 文案是否只保留一个核心结论
- 字幕是否完整
- 屏幕字是否过多
- 结尾 CTA 是否清晰
- 音频和字幕是否同步
