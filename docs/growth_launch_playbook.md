# 天眼增长落地手册

## 1. 商业模式

### A. 首单 POC
- 目标：用 1 次项目证明天眼的判断能力和交付质量
- 典型输出：执行摘要、渠道建议、内容建议、案例页
- 典型客户：新产品上市、招商材料、投融资前研究

### B. 标准模板包
- 目标：把高频行业做成标准化套餐
- 典型输出：行业模板报告、风险清单、渠道建议、脚本建议
- 适合行业：减重、保健品、护肤、数字健康

### C. 月费顾问
- 目标：形成稳定复购和持续现金流
- 典型输出：每周研究更新、每月复盘会、内容建议、项目评估

### D. 媒体与数字人代运营
- 目标：把研究能力升级为传播能力
- 典型输出：小红书内容矩阵、抖音短视频脚本、数字人口播视频

## 2. 小红书打法

### 内容结构
- 测评视频：真实体验 + 关键证据
- 对比笔记：与竞品或传统方案对比
- 用户故事：场景化问题与解决
- 专业科普：建立专业度

### 7 天启动动作
1. 确定 3 个核心痛点选题
2. 每个痛点写 2 条不同角度笔记
3. 上线 6 条内容测试封面与标题
4. 记录点击率、收藏率、私信率
5. 放大表现最好的 2 条结构

### 示例标题
- 为什么很多减重产品卖不动，问题不在配方，而在信任感
- 同样是功能产品，为什么有的品牌能在小红书先跑出来
- 我们把一个项目的渠道和内容放在一起推演后，发现了 3 个误区

## 3. 抖音打法

### 短视频公式
- 钩子：前 3 秒先打断
- 证据：给出 1 个清晰判断
- 解释：说明为什么
- CTA：导向直播、私域或案例页

### 直播结构
- 开场：问题抓手
- 中段：核心逻辑与证据
- 后段：优惠、问答、成交

### 示例开头
- 如果你现在还把所有预算平均投到每个渠道，基本就是在浪费钱。
- 我们把这个产品放进仿真系统后，发现它最不该先投的不是预算，而是错误渠道。

## 4. 数字人口播

### 适用场景
- 课程导学
- 案例复盘
- 客户汇报
- 产品讲解

### 60 秒脚本模板
1. 先抛出问题
2. 给出 1 个核心判断
3. 用 2 个证据支撑
4. 给出下一步建议

### 示例口播
今天我们不直接讨论怎么投流，而是先回答一个更关键的问题：这个项目真正适合先在哪个渠道建立认知。  
根据天眼的模拟结果，目标客群在小红书上的内容互动和信任建立效率明显更高，而抖音更适合在认知形成后承接转化。  
所以第一阶段不应该急着铺量，而应该先用内容建立判断框架，再把高表现内容迁移到直播和短视频转化场景。

## 5. 执行顺序
1. 先确定商业模式：卖 POC、模板包还是月费服务
2. 再确定主阵地：小红书优先还是抖音优先
3. 再确定内容生产方式：真人、数字人还是混合
4. 最后回到天眼平台，用案例与数据持续复盘
